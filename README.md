# Data & Search Project

Proyecto personal desarrollado como parte de mi formación en Ingeniería en Informática y Data Analytics.

## Objetivo

El objetivo del proyecto es desarrollar progresivamente un sistema capaz de almacenar, procesar, analizar y buscar información utilizando distintas herramientas y tecnologías.

El proyecto comenzará con la construcción y consulta de bases de datos mediante SQL y evolucionará hacia un motor de búsqueda capaz de encontrar y ordenar resultados de acuerdo con distintos criterios de relevancia.

Como aplicación final, se plantea desarrollar un buscador de oportunidades laborales que permita analizar ofertas y encontrar aquellas que presenten mayor compatibilidad con el perfil de un usuario.

## Tecnologías

Durante el desarrollo del proyecto se utilizarán progresivamente:

- SQL
- SQL Server
- Python
- Excel
- Power Query
- Power BI
- Git y GitHub

Más adelante podrán incorporarse herramientas de desarrollo web e inteligencia artificial.

## Funcionalidades proyectadas

El sistema buscará permitir:

- Almacenar información estructurada en una base de datos.
- Realizar consultas y filtros mediante SQL.
- Procesar y limpiar información utilizando Python.
- Buscar registros mediante distintos criterios.
- Crear un sistema de puntuación de relevancia.
- Ordenar resultados según su compatibilidad.
- Analizar tendencias y patrones dentro de los datos.
- Crear dashboards y visualizaciones.
- Desarrollar una interfaz para realizar búsquedas.
